# howausa-site

棉棉兔記帳（Howausa: Bunny Budget）的介紹網站（首頁、隱私權政策、使用條款，四種語言），用 GitHub Pages 發布。

首頁文字在 `landing.json`，「最近更新」讀主程式儲存庫的 `app/src/features/changelog/entries.ts`；隱私權政策、使用條款來源是主程式儲存庫的 `上架準備/隱私權政策.md`、`上架準備/使用條款.md`。改完執行 `python3 build.py <主程式儲存庫路徑>` 重新產生（需要 node）。外觀定案見主程式儲存庫 `設計稿/產品介紹網站_2026-11-12/定案.md`。
